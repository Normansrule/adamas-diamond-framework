# Changelog

Every release is a squash-merged pull request on `main`, tagged and published as a GitHub release.

| 0.35.0 | Entanglement Lab (labs/entangle.html) and docs/ENTANGLEMENT.md, from the new tested module `adamas.entangle`: can entanglement alone carry a message? No. The no-communication theorem [ghirardi1980] is checked numerically (random states, random measurements and unitaries: Bob's state changes by round-off only), a signaling game shows Bob guessing at 50 %, teleportation [bennett1993] reaches fidelity 1 only with Alice's two classical bits (1/2 without, (1 + v)/2 with a noisy pair, 2/3 for measure-and-phone), and a CHSH test [clauser1969] [cirelson1980] shows the correlation exceeding any local plan above v = 1/√2. A timeline labels each NV network result as demonstrated at cryogenic temperature and the room-temperature pre-shared-memory idea as proposed. The browser twin is golden-tested against the Python density-matrix results. Six classic references added (refs_m.psv, awaiting Crossref verification). |
| 0.34.0 | Build-program phase P4 (devices: hydrogen-terminated diamond FETs) written in full (docs/build/P4_devices.md, Figure 57, Build Program page): simulated PDK-0 monitor-die measurements analyzed as on real data, contact and sheet resistance from the TLM ladder, threshold matching on the four L = 2 µm enhancement FETs of the die, four copies each, pooled with Pelgrom area scaling [pelgrom1989] (χ² bound against the 200 mV traveler target), and mobility and threshold from the linear-regime transfer curve of the 16/2 µm FET with the TLM-measured contact resistance removed and its uncertainty propagated (exact on noise-free model data). Limits are ADAMAS targets from traveler steps S08 and S17; each check has a degraded twin with one process fault (contact residue, patchy termination, a too-thick gate oxide) that must fail; a correct run passes the gate at least 95 % of the time over 1000 simulated runs. Inputs are illustrative (PDK-0 design values). An independent review's 13 findings are fixed. |
| 0.33.0 | Build-program phase P3 (single NV) written in full (docs/build/P3_single_nv.md, Figure 56, Build Program page): simulated antibunching, hyperfine-resolved optically detected magnetic resonance (the ¹⁴N triplet, 2.147 MHz [felton2009], must be resolved) and a nuclear-spin Rabi oscillation after optical nuclear polarization [jacques2009], read through the electron (the method of [jelezko2004b]), fitted with the Data Lab's code; each test is set so a correct setup passes the whole gate at least 95 % of the time, and each runs on a degraded twin with one physical fault (two NVs in the focus, a power-broadened line, a detuned RF drive) that must fail. Inputs are illustrative except the hyperfine constant. The parts bill is computed from experiment C1; the nuclear RF source and the charge-state laser are not priced yet. An independent review's 13 findings are fixed (independent noise per test, a fixed background for the two-NV twin, the nuclear polarization step, a bias field instead of an idealized zero-field triplet, one-sided k for antibunching, acronyms). The Build Program page no longer clips its result tables on phones. |

Photo log `references/images.psv` with a license test (empty until Commons licenses are checked). QDL-04's implant step corrected: a 10 to 15 nm pair comes from one aperture, not two. |

Grill Me corrections: the "transistor" is split into the electron-nuclear conditional gate (CNOT 0.9992 [xie2023]) and the NV-NV dipolar coupler (Bell 0.824 [dolde2014] and gate 0.960 [joas2025] kept as different metrics); the drive line is classical; the photonic link is cryogenic only; readout gains nuclear single-shot (0.96 in 120 ms [dreau2013], new reference). Room-temperature link options are all labeled proposed. Machine Atlas M00 to M59 as code (`adamas.atlas`). Live coupler panel golden-tested against Python. 584 references. |
