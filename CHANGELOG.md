# Changelog

Every release is a squash-merged pull request on `main`, tagged and published as a GitHub release.

| Version | Highlights |
|---|---|
| 0.28.0 | Simulations, animations, and a ledger of what is left. Equation in the loop: seven live equation panels in five labs (Qubit: Rabi, Ramsey, echo; Photon: measured contrast; Power: hot switch; Wafer: crystal quality; Addressing: crosstalk), every symbol clickable with value, range, source, sensitivity, and a sparkline, assumption chips that turn amber outside the validity range, one Python registry (`adamas.loop`) with golden-tested browser arithmetic. Two new labs: Addressing (two NVs in one laser focus, told apart by crystal axis or field gradient; `adamas.addressing`) and Gate Bias (Pauli errors through CZ and H · CZ · H, checked against Stim; `adamas.gatebias`). Mistimed spin echo (`nv.echo_mistimed`). Three new animations (hot switch, addressing, gate bias). Copper conductivity and HPHT plate size sourced; sub-diffraction and implantation citations corrected; 582 references. Inline SVG icons instead of emoji, no eyebrow labels, keyboard-operable gallery, design rules in docs/DESIGN.md. docs/STATUS.md lists everything deferred or still assumed, with the reason. Electron 44.9.3, 0 npm vulnerabilities. An independent review's findings are fixed: the Addressing Lab drives the line of NV A farthest from NV B; line width uses the Gaussian dephasing of the rest of the site, 2√ln2/(πT₂*); the CNOT target bias is 1/(2η + 1), not 1/η; the loop golden test runs in CI; assumption chips state holds, outside, or assumed in words. |
| 0.27.0 | Audited release (Phase 0 expert audit, 80 findings, docs/AUDIT.md; includes 0.25 and 0.26). Power: incomplete ionization of a bulk boron-doped drift in R_on(T) (0.5 % ionized at 300 K), so a bulk-doped diamond switch loses to SiC at room temperature (loss ratio 0.40) and wins when hot (1.9× at 523 K); hole-mobility baseline 2000; critical field versus dislocation density; wafer history split into peer-reviewed and announced. Qubits: the 'charge preparation q ≈ 0.75' reading withdrawn, coherence range 0.78 to 0.998 recorded as a known discrepancy; measured contrast from the polarized state; ¹⁴N hyperfine 2.147 MHz; dislocation-strain T₂* model; addressing table for NVs 10 to 30 nm apart. Error correction: CZ-native circuits, bias kept on CZ only and at most 5 on CNOT (two-level qubits): XZZX threshold 1.81 % vs 0.86 % at bias 100 (3.25 % upper bound); distance table fixed (d = 15 and 21). Machine: RSA-2048 step count calibrated to the published 8 hours (2.1 years at 1 ms readout; 6.0 years upper bound), inter-cell link named as an assumption, within-model code ratios (173 M vs 58 M), code decision with a small but nonzero value of information. Process: hydrogen-plasma rule for the qubit variant, ENH mask, 20-step traveler, safety notes. App (v0.26 code review): service worker network-first for site files, desktop session permissions denied, download page detects phones and Intel Macs, desktop workflow also runs on package changes. 17 new references (part K) |
