# References

**466 references.** 34 were checked against an online source while the repository was built (marked ✅). The rest (marked 📚) were entered from knowledge of the literature and should be confirmed with `python tools/verify_refs.py` before you cite them in a paper. No Digital Object Identifiers (DOIs) are stored by hand, on purpose: the verifier fetches them from Crossref so that a mistyped DOI can never point at the wrong paper.

Cite in the docs and code as `[key]`. `python tools/check_citations.py` fails if a key is missing here.
