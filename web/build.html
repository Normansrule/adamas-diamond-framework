Would a good kit pass P1?

Each run simulates the A1 kit at five temperatures from 20 to 50 °C with its noise model, fits every spectrum the way the Data Lab does, and fits a slope through the centers. A run passes when the slope is within two combined standard errors of −74.2 kHz/K [acosta2010]. Repeat it and watch how often a kit that is exactly right still fails.

The latest run

A diamond's glow dips at a radio frequency that slides down a little as it warms up. If our homemade kit can see that slide and measure how big it is, it works as a thermometer. Even a perfect kit has noise, so sometimes it misses by chance; this page shows how often.
D(T) ≈ 2870 MHz + (dD/dT)(T − 300 K). Each spectrum is fitted with Lorentzians (Levenberg–Marquardt); the slope is a weighted least-squares line through the five centers. The pass band is ±2√(σ_fit² + σ_ref²), with σ_ref = 0.7 kHz/K from the published measurement, so a correct kit passes more often than the 95 % a band on the fit alone would give.
Noise model: contrast 1.2 %, 6 MHz full width, 0.12 % white noise per 0.25 MHz step (adamas.experiments; illustrative kit values, not a measurement). The browser draws its own random numbers, so individual runs differ from Python's; the tests compare the mean slope, the error-bar calibration, and the pass rate. The Python reference is adamas.build_program.p1_thermometer; the written phase is docs/build/P1_proof_of_concept.md.
