Machine Builder

Size a room-temperature diamond quantum computer for a real job. Error rates come from circuit-level simulations of NV hardware; every slider is a hardware choice.

Gate time follows the dipolar coupling: about 25 µs at 25 nm spacing, 8× faster at half the distance (chapter E5).

Runtime, log scale: this machine versus a superconducting machine at today's measured error suppression
A big quantum job needs millions of qubits working together and checking each other's mistakes over and over. Diamond qubits don't need a freezer and fit on a chip smaller than a stamp, but each check is slow, so big jobs can take years. Make the reading faster and watch the time drop.
Each logical qubit is a d × d surface-code patch. The code distance d is the smallest odd number that keeps the total failure below 1%: n_L · steps · d · p_L(d) ≤ 0.01, with p_L(d) = A·Λ^(−(d+1)/2). One syndrome round takes preparation + four gates + readout, and each logical step takes d rounds.
A and Λ are fitted to Stim + PyMatching circuit-level simulations (d = 3, 5, 7; 200,000 shots) with NV noise: 0.3% link, 1% readout, 0.2% preparation, and idle depolarization during readout; Λ is forced non-increasing in readout time. The NV Λ assumes a 0.3% link error that has not been demonstrated, while the superconducting reference uses the measured Λ = 2.14. Workloads are illustrative scales, not published algorithm counts.
