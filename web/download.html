Pick your system

⊞ Windows 10 and 11

Installer (recommended) .exe · x64 Portable, no install .exe · x64

The app is not code-signed yet, so SmartScreen may say "Windows protected your PC". Choose More info → Run anyway. Works from WSL too: run the installer from Windows.

macOS 12 and newer

Apple silicon (M1 to M4) .dmg · arm64 Intel Mac .dmg · x64

Not notarized yet: the first time, right-click the app in Applications and choose Open, then Open again.

🐧 Linux

AppImage, any distribution .AppImage · x86_64 Debian and Ubuntu .deb · amd64

AppImage: chmod +x ADAMAS-linux-x86_64.AppImage then run it. Ubuntu 24.04 and newer may also need sudo apt install libfuse2t64. Deb: sudo apt install ./ADAMAS-linux-amd64.deb.

Check a download: sha256sum -c SHA256SUMS.txt --ignore-missing after downloading SHA256SUMS.txt. All releases: GitHub releases.

No download

Install the website as an app

In Chrome or Edge, use the install icon in the address bar (or the button above). On a phone, use "Add to Home Screen". It opens in its own window and keeps working offline after the first visit.

For developers

Run it from Python

Builds the site from your checkout and opens it in a native window (with pywebview) or your browser.

$ git clone https://github.com/Normansrule/adamas-diamond-framework
$ cd adamas-diamond-framework && pip install -e ".[app]"
$ adamas app
